# WriteNow

A writing studio for planning and drafting a book. Notes, chapter outlines, a codex of characters and places, and a manuscript compiler.

It runs entirely on your device. No account, no server, no network requests of any kind. Your writing never leaves the device it was written on.

---

## Install it on your Home Screen

**Do this before you start writing.** On iPhone and iPad, Safari erases the storage of any site you haven't visited in seven days. A Home Screen install is exempt from that rule. Used as a plain browser tab, your work can disappear; installed, it stays.

### iPhone and iPad

1. Open the link in **Safari**. Other browsers can't do this step.
2. Tap the **Share** button — the square with an arrow pointing up. It's at the bottom of the screen on iPhone, the top on iPad.
3. Scroll down the list and tap **Add to Home Screen**.
4. Tap **Add**, top right.

The icon appears on your Home Screen. Open it from there from now on, not from Safari.

### Android

1. Open the link in **Chrome**.
2. Tap the **⋮** menu, top right.
3. Tap **Add to Home screen**, or **Install app** if that's what it says.
4. Tap **Install**.

### Windows and Mac

1. Open the link in **Chrome** or **Edge**.
2. Click the **install icon** in the address bar — a monitor with a downward arrow.
3. Click **Install**.

If you don't see the icon, use the **⋮** menu → **Cast, save and share** → **Install page as app**.

---

## After installing

**It works offline.** Once it has loaded, you can write with no connection. On a plane, in a basement, with Wi-Fi off.

**It updates itself.** Open it with a connection and you get the current version. Nothing to reinstall.

**Back up anyway.** Settings → Backup & Restore → Copy backup. The app holds your work in browser storage, which is durable but not permanent — a device wipe or a browser reset takes it with everything else. The backup is a single file you keep.

**Two devices don't sync.** Each install is its own copy. To move work between them, take a backup on one and restore it on the other.

---

## Removing it

Delete the icon the way you'd delete any app. On iPhone and iPad that also erases the writing stored in it, so take a backup first if you want to keep it.
