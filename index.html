General

In your classroom

WriteNow Jr. teaches the three kinds of writing most middle-school standards ask for: stories (narrative), true stories (personal narrative), and explaining and opinion writing (informational and argument). Each has its own course of twenty short lessons. Every lesson explains one idea, shows a good example, names a common mistake, and ends with one small task the student does in the app.

Pacing. One or two lessons fit a class period, with time to write. The app checks most tasks itself and moves the student on when the task is done, so a class can work at different speeds without anyone waiting.

Privacy. There are no accounts, no internet connection and no data collection. Nothing a student writes leaves the device unless they copy or save it themselves.

Handing in work. In the Book tab, a student can copy the whole piece or save it as a file that opens in any browser and prints cleanly. From the books button, Export this book saves a single book as a file you can collect.

Shared devices. If students take turns on a device, choose “Students take turns” the first time the app opens, or switch it on below. Each student's work then lives in a file they keep, not on the device. Have them save it somewhere that's theirs: their school Google Drive or OneDrive, a USB stick, or a class folder you collect. On Chromebooks where students sign in with their own account, each account already keeps its own work.

Getting unstuck. The Learn tab has every lesson, a search that takes questions in a student's own words, and a list of the troubles students hit most. The ? beside each chapter prompt opens the lessons for that part of the writing.

This device

When students take turns, the app opens on a start screen. Each student opens the file they saved last time, or starts new. When they're done, Save and finish saves one file holding their writing, their lessons and where they are, then clears the device for the next student.

Printable lesson sheets

One page per lesson: the idea, an example, what to watch out for, and the task, with lines for notes. Each downloads as a file that opens in any browser; print it from there.
